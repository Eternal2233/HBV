# Hepatitis B policy modelling

The [V1.1 release](https://github.com/Eternal2233/HBV/releases/tag/V1.1) contains the analysis code, model inputs and saved results for *Population impact and opportunity costs of introducing a finite-course functional cure for chronic hepatitis B: a global dynamic modelling study*.

- [Supplementary Data 1](https://github.com/Eternal2233/HBV/releases/download/V1.1/Supplementary-Data-1-V1.1.zip) contains the analysis code, model inputs, fitted parameters and environment requirements.
- [Supplementary Data 2](https://github.com/Eternal2233/HBV/releases/download/V1.1/Supplementary-Data-2-V1.1.zip) contains the saved model outputs, conditional PSA draws, derived force-of-infection values and source tables.

See the [reproduction guide](REPRODUCE.md) to run the model and verify the saved results.
